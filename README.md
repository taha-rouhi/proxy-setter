# Proxy Setter - تنظیم سریع پراکسی ویندوز

ابزار ساده و گرافیکی برای فعال و غیرفعال کردن پراکسی سیستم ویندوز با یک کلیک.

## ویژگی‌ها
- ذخیره آخرین آدرس پراکسی
- رابط کاربری ساده و زیبا
- نمایش وضعیت فعلی پراکسی
- نسخه EXE آماده (بدون نیاز به نصب پایتون)

## نحوه استفاده
1. برنامه را اجرا کنید.
2. آدرس پراکسی را وارد کنید (مثال: `127.0.0.1:8080`)
3. دکمه **پراکسی را فعال کن** را بزنید.

## ساخت نسخه EXE

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --icon=icon.ico proxy_setter.py
